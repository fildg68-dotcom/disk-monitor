# Disk Monitor 🐍

Проста консольна програма для моніторингу заповнення диска в Linux, написана мовою Python.

Проєкт створений для практичного вивчення Python, Linux та Git. Програма поступово розвивається в процесі навчання.

## Можливості

- Визначення загального, використаного та доступного простору на диску.
- Відображення обсягу пам'яті в GiB.
- Обчислення відсотка заповнення диска.
- Автоматична перевірка кожні 120 секунд.
- Попередження при заповненні диска на 90% або більше.
- Запам'ятовування попереднього стану для уникнення повторних попереджень.
- Запис змін стану в `events.log` із датою та часом.

## Вимоги

- Linux
- Python 3
- Додаткові бібліотеки не потрібні.

## Запуск

Клонуйте репозиторій:

```bash
git clone https://github.com/fildg68-dotcom/disk-monitor.git
cd disk-monitor
```

Запустіть програму:

```bash
python3 main.py
```

Для зупинки використовуйте `Ctrl+C`.

## Приклад роботи

```text
Час перевірки: 15.11.2026 14:30:00
Загалом місця: 1087.24 GiB
Використовується: 975.62 GiB
Вільно: 56.32 GiB
Заповнення: 94.5
Місця на диску критично мало
```

Програма перевіряє файлову систему, що містить `/`.
